API Reference

    
Full programmatic access to all IPL data. Filter, paginate, sort — or let the AI write the SQL for you.

          GET
          /api/tables
          List all tables
          ▾
        

        

          
Returns every available table and its ordered column list. Use this to discover what data is accessible before building filter queries.

          
Parameters

          
None — no parameters required.

          GET
          /api/tables/{table}
          Query a table
          ▾
        

        

          
Paginated, filterable access to any IPL table. Pass column names as query params to filter by exact value. All other query parameters act as column filters.

          
Parameters

          

            
NameInTypeRequiredDescription

            
              
tablepathstringrequiredTable name. One of: deliveries, matches, innings, players, teams, match_players, officials, powerplays, player_season

              
limitqueryintegeroptionalRows to return. Default 100, max 1000.

              
offsetqueryintegeroptionalRows to skip. Default 0.

              
order_byquerystringoptionalColumn name to sort by.

              
order_dirquerystringoptionalasc or desc. Default asc.

              
*columnquerystringoptionalAny column name as a filter param. E.g. batter=V+Kohli or phase=powerplay
