Keep responses short and direct — no preamble, no trailing summaries.

**Why:** User works fast and doesn't need hand-holding.

**How to apply:** Lead with the action or answer. Skip filler. Only explain when something is non-obvious.

---

Remove unnecessary emojis from UI — keep it professional and clean.

**Why:** User wants a polished, Claude-like aesthetic, not a playful dashboard.

**How to apply:** Only use emojis in branding (hero section) and user-facing prompt chips. Strip from all buttons, tabs, labels, KPI cards, sidebars.

---

Always push to git after making changes — don't leave uncommitted work.

**Why:** User noticed a missed commit and called it out explicitly.

**How to apply:** After every meaningful change, stage + commit + push without being asked.
